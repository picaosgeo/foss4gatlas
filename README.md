# foss4gatlas
FOSS4G Atlas

FOSS4G Atlas を公開しました。230件の使用記録を世界地図・年別グラフ・検索できる一覧表で見られます（分類の凡例をクリックでレイヤー切替、バーをクリックで年絞り込み）。CSV と GeoJSON も添付しています。

調査で分かった重要な点を3つ:

1. 語の発祥は日本・大阪でした。 OSGeo Wiki と Raghavan 本人のメーリングリスト投稿によると、2004年初頭に大阪市立大学の Venkatesh Raghavan が GRASS/MapServer 国際化プロジェクトの中で考案し、2004年3月の同大学紀要『情報学研究』の論文で初めて活字化されています。foss4g.org ドメインは2003年に Raghavan・升本眞二名義で登録され、2007年に OSGeo へ寄贈されました。

2. 2004年バンコク会議は「初出」ではありません。 当時の正式名称は Free/Libre and Open Source Software for Geoinformatics: GIS-GRASS Users Conference で、会議名として FOSS4G が使われたのは2006年ローザンヌ以降です。バンコクを「第1回」とするのは後付けの整理でした。

3. 会議以外の用法は教育分野に集中しています。 コロラド大学デンバー校の FOSS4G Lab と正規修了証プログラム（キャップストーン科目名も "FOSS4G Systems Integration Lab"）、インド政府 NeGD の国家 FOSS4G ポータル、FOSS4G Academy（米 NISGTC の5科目カリキュラム）などです。一方 OSGeo ローカルチャプターには FOSS4G を名乗るものが一つもありません。

なお、ご依頼の際に想定されていたかもしれない「FOSS4G Europe 2013 ジローナ」は裏付けが取れませんでした。公式には2012 Prague・2013 Bucharest が FOSS4G-CEE、2014 Bremen が Europe 第1回です（Girona はスペイン SIGTE の Jornadas de SIG Libre の開催地）。同様に開催都市や所属都市が確定できなかった22件には「要確認」フラグを立てています。
