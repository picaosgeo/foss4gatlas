FOSS4G Atlas 「FOSS4G」という語は2004年、大阪市立大学の Venkatesh Raghavan らが GRASS/MapServer 国際化プロジェクトの中で考案しました。以来この語は、世界大会・地域大会・国内イベント・査読論文・政府施策・大学カリキュラムへと広がっています。data/foss4g_usage.geojson を読み込み、その使用地点を年・分類・内容とともに地図化します。

語の起源について

OSGeo Wiki は「2004年初頭、GRASS と MapServer の国際化に取り組む研究グループが Free and Open Source Software for Geoinformatics の略語として考案した」と記述し、2004年3月の大阪市立大学紀要論文を初出文献として挙げています。Raghavan 本人も2007年の OSGeo メーリングリストで考案者であると述べています。

一方、同年9月のバンコク会議の当時の正式名称は Free/Libre and Open Source Software for Geoinformatics: GIS-GRASS Users Conference であり、会議名として FOSS4G が使われたのは2006年ローザンヌ以降です。バンコクを「第1回」とするのは後付けの整理です。

データ構造

各 Feature は Point ジオメトリと次の properties を持ちます。category（origin / global / regional / national / paper / product）、year、when、name、city、country、description、confidence（confirmed / unverified）、source_url。

描画側は city × country × category で集約して count を持つ点に変換し、分類ごとに別レイヤーへ振り分けて circle-translate で放射状にずらしています。

データの限界

要確認 の付いた記録は、開催都市・所属都市・開始年のいずれかが一次情報で確定できていないものです。座標は都市の代表点であり、会場や機関の正確な位置ではありません。

網羅を主張するものではなく、公開情報から確認できた範囲の記録です。陸地ポリゴンは Natural Earth 110m（public domain）を簡略化したものです。
